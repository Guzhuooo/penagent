4) Honest boundaries
- This verification used the explicit development-mode curl transport (services/net/dev.js) with
  a synthetic key and a private LAN mock. It does NOT unlock production: flat HTTP remains
  fail-closed (TLS verification off, no trustworthy HTTP status), and no real endpoint/real key
  was sent. Production still requires the native/independently verified secure adapter.
- One retry during iteration, launched from a stale page/realm after overwrite-install without a
  process restart, ended with status=error/toolCalls=0; a clean uninstall/install reproduced the
  successful loop above. Install over a running realm is not claimed as a reliable hot-reload path.
- file_exec runs arbitrary shell commands by user opt-in; it is sandboxed to the workspace cwd but
  is still a high-risk capability. Started child processes cannot be guaranteed to be physically
  killed after cancellation; /bin/timeout bounds the wall clock.
- IME, multi-resolution, memory/GC trends, real endpoint conversation and native .so remain
  unverified for 0.3.0. See docs/VALIDATION.md.
